Analysis (Technical)

This page summarizes Phase 1-5 outputs from the reproducible pipeline. Structural confidence is evaluated with cross-validation and falsification tests. No semantic decipherment is claimed.

Key takeaway The expanded corpus ranks the syllabary-like structural model highest, while confidence remains capped by weak template predictability and adversarial tests that do not all behave as expected.

Can the Current Evidence Support 85%?

Not yet. The generated confidence matrix reaches 71.36%, and random-weight sensitivity runs cap below 85%. The path to 85% would require the weak components to improve, especially template predictability and out-of-sample performance, not merely a more favorable explanation of the same evidence.

  • For: corpus breadth, provenance tracking, normalization stability, and AB22 positional concentration.
  • Against: semantic and phonetic claims remain low confidence; shuffled-sequence falsification currently shows no degradation under the winning model.
  • Needed: independent inscriptions or held-out artifacts where the model predicts structure before inspection.
